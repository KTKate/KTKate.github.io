# Assets

## Cut-paper hero

`public/images/paper-stacks.webp` is original generated artwork created for this portfolio revision using the built-in image generation tool. It depicts three separate physical stacks in violet, amber, and magenta on navy. No client or project interface is depicted. The supplied inspiration images were inspected for material and construction reference; they are not redistributed in this repository.

The generated 1536 × 1024 PNG was encoded as WebP at quality 87 for delivery. All three stack images share that one cached resource. CSS clipping separates the stacks for a brief entrance animation, which is disabled by reduced-motion preference.

## Typeface

`src/assets/manrope.ttf` is the variable Manrope typeface from the Google Fonts repository. Its SIL Open Font License is included as `src/assets/Manrope-OFL.txt`.

Source: https://github.com/google/fonts/tree/main/ofl/manrope
